## What Abbon can do

| Type | How to answer |
| --- | --- |
| single choice | one box |
| multiple choice | several boxes; partial scoring possible |
| short answer | type a word, optionally case-sensitive |
| number | comma or point, tolerance, unit |
| fill-in-the-gaps | typed gaps or drop-down lists |
| expression | type a formula: any equivalent form is accepted |
| flashcard | turn the card, say whether you knew it |

## Formulas and chemistry

Formulas are written in LaTeX and drawn offline: $\int_0^1 x^2\,dx = \dfrac{1}{3}$.

Chemistry uses mhchem: $\ce{CH4 + 2O2 -> CO2 + 2H2O}$.

## Practice or exam

- **Practice**: correction after each question, explanations, review box.
- **Exam**: score and answers at the end, optional time limit.

## Your own quizzes

Write them in the editor, import them (.qcm, GIFT), or install modules from the quiz catalogue. A quiz or a module can be exported as a website for shared hosting.
