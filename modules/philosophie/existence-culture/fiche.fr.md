## Notions et repères d'auteurs

| Notion | Thèse à connaître |
| --- | --- |
| La conscience | Descartes : « je pense, donc je suis », première certitude |
| L'inconscient | Freud : « le moi n'est pas maître dans sa propre maison » |
| Le bonheur | Épicure : ataraxie, tri des désirs ; Aristote : le bonheur, fin ultime |
| L'art | Platon : l'imitation éloigne du vrai ; Kant : le beau plaît universellement sans concept |
| Le langage | Descartes : la parole adaptée au sens est signe de pensée |
| Le temps | Augustin : « si personne ne me le demande, je le sais » ; Bergson : la durée vécue |
| Le travail | Hegel : il forme l'esclave ; Marx : il est aliéné dans le salariat |
| La technique | Descartes : « comme maîtres et possesseurs de la nature » ; Jonas : principe responsabilité |
| La religion | Marx : « l'opium du peuple » ; Nietzsche : « Dieu est mort » ; Pascal : le cœur et la foi |

Penser une notion, c'est poser un problème : par exemple, la conscience me donne-t-elle accès à ce que je suis vraiment ?
