## Quelques repères du programme

| Repère | À retenir |
| --- | --- |
| Légal / légitime | conforme à la loi / conforme au droit, au juste |
| Persuader / convaincre | agir sur les passions / sur la raison |
| Obligation / contrainte | règle reconnue par une volonté libre / force qui s'impose |
| En fait / en droit | ce qui est / ce qui doit être, ce qui est fondé |
| Origine / fondement | commencement dans le temps / justification en raison |
| Croire / savoir | tenir pour vrai sans preuve suffisante / avec des raisons objectives |
| Contingent / nécessaire | qui pourrait ne pas être / qui ne peut pas ne pas être |
| Transcendant / immanent | extérieur et supérieur / intérieur à la chose |
| En acte / en puissance | réalisé / capacité de devenir |
| Universel / général / particulier / singulier | tous, sans exception / la plupart / certains / un seul |

Les repères ne sont pas des sujets en eux-mêmes : ils servent à analyser un sujet et à construire une distinction utile dans une dissertation.
