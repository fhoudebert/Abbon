## embarazada · single
En espagnol, *embarazada* signifie :

- [ ] embarrassée
- [x] enceinte
- [ ] fatiguée

> *Estar embarazada* : être enceinte. « Je suis embarrassée » se dit *estoy avergonzada* (j'ai honte) ou *me siento incómoda* (je suis mal à l'aise). Faux ami célèbre, source de quiproquos.

## actualmente · single
*Actualmente* signifie :

- [x] actuellement
- [ ] en réalité
- [ ] éventuellement

> *Actualmente* veut bien dire « actuellement, en ce moment » : ce n'est pas un faux ami en espagnol. Le piège vient de l'anglais *actually* (« en réalité »), qui se dit *en realidad* ou *de hecho*.

## constipado · single
Si quelqu'un vous dit *Estoy constipado*, il veut dire :

- [ ] je suis constipé
- [x] j'ai un rhume
- [ ] je suis très fatigué

> En Espagne, *estar constipado* signifie « être enrhumé » (*un constipado*, un rhume). La constipation se dit *estreñimiento* (*estoy estreñido*).

## libreria · single
*Una librería* est :

- [ ] une bibliothèque
- [x] une librairie
- [ ] un livre de poche

> *Librería* : librairie, où l'on achète des livres (et aussi une étagère à livres). La bibliothèque, où l'on emprunte, se dit *biblioteca*.

## exito · single
*Éxito* signifie :

- [ ] sortie
- [x] succès
- [ ] excitation

> *Tener éxito* : avoir du succès, réussir. La sortie se dit *salida* ; le piège vient de l'anglais *exit*.

## carpeta · single
*Una carpeta* est :

- [x] une chemise, un dossier (pour ranger des papiers ou des fichiers)
- [ ] une carpette
- [ ] un tapis de sol

> *Carpeta* : chemise cartonnée, classeur, et en informatique un dossier. La carpette se dit *alfombrilla* ou *tapete*, le tapis *alfombra*.

## ir-al-medico · single
Comment dit-on « Je vais chez le médecin » ?

- [x] Voy al médico.
- [ ] Voy a médico.
- [ ] Voy en el médico.

> « Chez » n'a pas d'équivalent direct : on va « au médecin », *ir al médico* (*a* + *el* = *al*). De même : *voy al dentista, voy a casa de Ana* (chez Ana).

## para-ti · single
Complétez : *Este regalo es ___ ti.*

- [ ] por
- [x] para
- [ ] de

> *Para* indique le destinataire ou le but : *es para ti* (c'est pour toi). *Por* exprime la cause, le moyen ou l'échange : *gracias por el regalo* (merci pour le cadeau). Distinction difficile pour les francophones, qui n'ont que « pour ».

## buscar · single
Quelle phrase signifie « Je cherche mes clés » ?

- [ ] Busco por mis llaves.
- [x] Busco mis llaves.
- [ ] Buscar mis llaves estoy.

> *Buscar* se construit directement : *busco mis llaves*. Pour une personne, on ajoute le *a* personnel : *busco a mi hermano*.

## que-tal · single
*¿Qué tal?* signifie :

- [ ] Pourquoi ?
- [x] Comment ça va ?
- [ ] Quelle heure est-il ?

> *¿Qué tal?* : « Comment ça va ? » ; suivi d'un nom, « Comment s'est passé… ? » (*¿Qué tal el viaje?*, le voyage s'est bien passé ?). « Pourquoi » se dit *¿por qué?*, l'heure *¿qué hora es?*
