## Faux amis

| Espagnol | Sens | Le mot français se dit |
| --- | --- | --- |
| *embarazada* | enceinte | embarrassée : *avergonzada* |
| *constipado* | enrhumé | constipé : *estreñido* |
| *librería* | librairie | bibliothèque : *biblioteca* |
| *éxito* | succès | sortie : *salida* |
| *carpeta* | chemise, dossier | carpette : *alfombrilla* |
| *salir* | sortir | salir : *ensuciar* |
| *largo* | long | large : *ancho* |

*Actualmente* signifie bien « actuellement » : le faux ami est l'anglais *actually* (*en realidad*).

## Prépositions

- « Chez » : *ir al médico* (*a* + *el* = *al*), *ir a casa de Ana*.
- **para** : destinataire, but (*es para ti, estudio para aprender*) ; **por** : cause, moyen, échange (*gracias por todo*).
- *buscar algo* sans préposition ; devant une personne, *a* personnel : *busco a mi hermano*.

## Formules courantes

*¿Qué tal?* (comment ça va ?), *¿Qué tal el viaje?* (comment s'est passé le voyage ?), *¿Por qué?* (pourquoi ?), *¿Qué hora es?* (quelle heure est-il ?).
