## Expressions courantes

| Espagnol | Sens |
| --- | --- |
| *tener ganas de* | avoir envie de (*tener que* : devoir) |
| *no pasa nada* | ce n'est pas grave |
| *me da igual* | ça m'est égal |
| *estar hecho polvo* | être épuisé |
| *¡ojalá!* + subjonctif | pourvu que, si seulement |
| *tomar el pelo* | se moquer de, faire marcher |
| *echar una mano* | donner un coup de main |
| *ser pan comido* | être du gâteau, très facile |
| *estar en las nubes* | être dans la lune |
| *¡vale!* | d'accord (Espagne) |

Le verbe *echar* (jeter) entre dans beaucoup d'expressions : *echar de menos, echar una mano, echar la siesta*.
