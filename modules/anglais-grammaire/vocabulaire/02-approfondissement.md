## bookshop · single
*I bought this novel at the ___ near the station.*

- [x] bookshop
- [ ] library
- [ ] librairy
- [ ] book library

> Une librairie (où l'on achète) est une *bookshop* (britannique) ou *bookstore* (américain). *Library* est une bibliothèque, où l'on emprunte.

## injured · single
*Two passengers were slightly ___ in the accident.*

- [x] injured
- [ ] blessed
- [ ] wounded by bullets
- [ ] hurted

> « Blessé » : *injured* (accident), *wounded* (arme, guerre), *hurt* (participe passé irrégulier de *hurt*, sans *-ed*). *Blessed* veut dire « béni ».

## attend · single
*More than 200 people ___ the conference last week.*

- [x] attended
- [ ] assisted
- [ ] assisted to
- [ ] participated

> *Attend* : assister à, être présent (*attend a meeting, a class*). *Assist* : aider. *Participate* existe, mais avec *in* (*participated in the conference*).

## profit · single
*The company made a record ___ of €3 million last year.*

- [x] profit
- [ ] benefit
- [ ] earning
- [ ] advantage

> « Bénéfice » au sens financier : *profit*. *Benefit* : un avantage, un bienfait (*the benefits of exercise*), ou une allocation sociale.

## sensitive · single
*He's very ___; he gets upset if you criticise him.*

- [x] sensitive
- [ ] sensible
- [ ] sensitivity
- [ ] sensibly

> *Sensitive* : sensible, susceptible. *Sensible* : raisonnable, sensé (*a sensible decision*). Un faux ami très testé.

## take-exam · single
*I ___ my driving test tomorrow morning. Wish me luck!*

- [x] am taking
- [ ] am passing
- [ ] am making
- [ ] am doing a pass

> « Passer un examen » : *take* (ou *sit*) *an exam*. *Pass an exam* signifie le réussir ; *fail*, y échouer. *I'm passing my test tomorrow* serait bien présomptueux.

## actual · single
*The ___ cost of the project was twice the original estimate.*

- [x] actual
- [ ] current
- [ ] actualised
- [ ] present

> *Actual* : réel, effectif. « Actuel » se dit *current* ou *present* (*the current situation*). Phrase type du TOEIC, en lien avec un budget.

## diary · single
*I've written the appointment in my ___.*

- [x] diary
- [ ] agenda
- [ ] calendar of meeting
- [ ] journal

> L'agenda personnel est un *diary* (britannique) ou *planner* (américain). *Agenda* désigne l'ordre du jour d'une réunion : *the first item on the agenda*.

## do-favour · single
*Could you ___ me a favour and post this letter?*

- [x] do
- [ ] make
- [ ] give
- [ ] render

> *Do someone a favour* (rendre service). Comparer : *make an effort, make a suggestion, do research, do damage*.

## complete · single
*We finally ___ the project late last night.*

- [x] completed
- [ ] achieved
- [ ] realised
- [ ] terminated

> « Achever » : *complete, finish*. *Achieve* : atteindre, accomplir (*achieve a goal, achieve success*). *Realise* : se rendre compte (rarement « réaliser un projet », qui se dit *carry out*).
