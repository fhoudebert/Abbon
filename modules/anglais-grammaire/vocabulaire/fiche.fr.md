## Faux amis

| Mot anglais (sens) | Le mot français se dit |
| --- | --- |
| *actually* (en fait) | actuellement : *currently* |
| *actual* (réel) | actuel : *current* |
| *eventually*, *eventual* (finalement, final) | éventuellement : *possibly* |
| *library* (bibliothèque) | librairie : *bookshop* |
| *sensible* (raisonnable) | sensible : *sensitive* |
| *attend* (assister à) | assister (aider) : *assist* |
| *achieve* (atteindre, accomplir) | achever : *complete, finish* |
| *agenda* (ordre du jour) | agenda : *diary* |
| *lecture* (conférence, cours) | lecture : *reading* |
| *deception* (tromperie) | déception : *disappointment* |
| *formation* (constitution, formation géologique) | formation professionnelle : *training* |
| *prevent* (empêcher) | prévenir (avertir) : *warn* |
| *blessed* (béni) | blessé : *injured, hurt* |
| *benefit* (avantage) | bénéfice : *profit* |
| *pass an exam* (réussir un examen) | passer un examen : *take an exam* |

## Make ou do

- **make** : créer, produire : *a mistake, a decision, progress, an effort, a noise, money, a phone call*.
- **do** : tâches, activités : *homework, the dishes, a favour, business, research, your best*.
- Autres collocations : *pay attention, play a role, raise an issue, take an exam*.

## Paires de verbes

- *lend* (prêter) / *borrow* (emprunter) ; *say something* / *tell someone something*.
- *raise* (transitif, régulier : *raise prices*) / *rise* (intransitif : *rise – rose – risen*).

## Dénombrable ou non

- Indénombrables : *information, advice, news, furniture, luggage, equipment, progress, training* : pas de pluriel, pas de *a / an* ; *a piece of advice*.
- *how many* + pluriel, *how much* + indénombrable.

## -ed ou -ing

*bored* (qui s'ennuie) / *boring* (ennuyeux) ; de même *interested / interesting, tired / tiring, surprised / surprising*.
