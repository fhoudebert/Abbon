## eventual · single
*After a tense final, the ___ winner was announced just before midnight.*

- [x] eventual
- [ ] possible
- [ ] eventually
- [ ] potential

> L'adjectif *eventual* signifie « final, qui finit par l'être », comme l'adverbe *eventually*. « Éventuel » se traduit par *possible* ou *potential*.

## make-progress · single
*She has ___ a lot of progress since September.*

- [x] made
- [ ] done
- [ ] taken
- [ ] got

> *Make progress* (indénombrable : pas de *a progress*, pas de *progresses*). Autres collocations avec *make* : *make an impact, make a difference, make arrangements*.

## play-role · single
*He ___ a key role in the negotiations.*

- [x] played
- [ ] had
- [ ] made
- [ ] did

> *Play a role / a part in something*. « Jouer un rôle » est l'un des rares cas où le verbe français se traduit mot à mot ; *have a role* existe, mais pas dans cette collocation.

## pay-attention · single
*Please ___ attention to the safety instructions.*

- [x] pay
- [ ] make
- [ ] do
- [ ] take

> *Pay attention to* : faire attention à. On « paie » aussi *a visit, a compliment, tribute*.

## raise-issue · single
*She ___ an important issue at the meeting.*

- [x] raised
- [ ] rose
- [ ] arose
- [ ] risen

> *Raise* (transitif, régulier) : soulever, augmenter quelque chose (*raise a question, raise prices*). *Rise* (intransitif, irrégulier : *rose, risen*) : monter tout seul. *An issue arose* : une question s'est posée.

## prices-risen · single
*Energy prices have ___ sharply this winter.*

- [x] risen
- [ ] raised
- [ ] rised
- [ ] arisen

> Les prix montent d'eux-mêmes : *rise – rose – risen*. *The government has raised taxes* : quelqu'un les augmente.

## disappointment · single
*The results were a huge ___ for the whole team.*

- [x] disappointment
- [ ] deception
- [ ] delusion
- [ ] deceit

> « Déception » : *disappointment*. *Deception* et *deceit* signifient « tromperie », *delusion* « illusion, idée délirante ».

## training · single
*The company offers excellent ___ for new employees.*

- [x] training
- [ ] formation
- [ ] trainings
- [ ] formings

> La formation professionnelle : *training* (indénombrable). *Formation* désigne une formation géologique ou militaire, la constitution de quelque chose (*the formation of a new government*).

## lecture · single
*Professor Brown gave a fascinating ___ on climate change.*

- [x] lecture
- [ ] reading
- [ ] conference
- [ ] lesson of reading

> *Lecture* : un cours magistral, une conférence (un exposé devant un public). « La lecture » se dit *reading*. *Conference* : un congrès, avec plusieurs intervenants.

## warned · single
*Nobody ___ us about the strike, so we went to the station for nothing.*

- [x] warned
- [ ] prevented
- [ ] advised to
- [ ] informed to

> « Prévenir » au sens d'avertir : *warn* (ou *let someone know, tell*). *Prevent* signifie « empêcher » : *The strike prevented us from travelling.*
