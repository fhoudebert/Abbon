## enjoy-ing · single
*I enjoy ___ new languages.*

- [x] learning
- [ ] to learn
- [ ] learn
- [ ] learned

> *Enjoy* est suivi du gérondif (*-ing*). Le français « aimer apprendre » (infinitif) pousse vers *to learn*. Même chose pour *avoid, finish, mind, suggest, keep, consider*.

## avoid-ing · single
*They avoid ___ late.*

- [x] arriving
- [ ] to arrive
- [ ] arrive
- [ ] arrived

> *Avoid* + *-ing* : *avoid arriving late, avoid making mistakes*. L'infinitif est une erreur classique.

## suggest-ing · single
*He suggested ___ by train.*

- [x] going
- [ ] to go
- [ ] go
- [ ] went

> *Suggest* + *-ing*, ou *suggest that we go*. *He suggested to go* est un calque de « il a proposé d'y aller ».

## decide-to · single
*She decided ___ a new job.*

- [x] to change
- [ ] changing
- [ ] change
- [ ] changed

> *Decide* est suivi de l'infinitif avec *to*, comme *want, hope, plan, agree, refuse, promise*. Ces verbes tournent souvent vers un projet, un futur.

## difficult-to · single
*It's difficult ___ this problem.*

- [x] to solve
- [ ] solving
- [ ] solve
- [ ] solved

> *It's* + adjectif + *to* + verbe : *it's easy to understand, it's important to check*. Le gérondif se met en sujet : *Solving this problem is difficult.*

## used-to-ing · single
*I'm used to ___ early in the morning.*

- [x] waking up
- [ ] wake up
- [ ] woke up
- [ ] wakes up

> Dans *be used to* (« être habitué à »), *to* est une préposition : elle est suivie d'un nom ou d'un gérondif. Ne pas confondre avec *I used to wake up early* (« autrefois, je me levais tôt »).

## look-forward · single
*I'm looking forward ___ you.*

- [x] to seeing
- [ ] to see
- [ ] seeing
- [ ] see

> *Look forward to* : *to* est une préposition, donc *-ing*. Formule de fin de courriel : *I look forward to hearing from you.* Une faute très repérée au TOEIC.

## dont-have-to · single
*You ___ wear a suit. It's an informal event.*

- [x] don't have to
- [ ] mustn't
- [ ] shouldn't
- [ ] can't

> *Don't have to* : ce n'est pas nécessaire (« tu n'es pas obligé »). *Mustn't* : c'est interdit. En français, « tu ne dois pas » ne fait pas cette distinction : piège majeur.

## mustnt · single
*You ___ smoke here; it's prohibited.*

- [x] mustn't
- [ ] don't have to
- [ ] should
- [ ] could

> Interdiction : *mustn't* (ou *can't*). *You don't have to smoke here* voudrait dire « tu n'es pas obligé de fumer ici ».

## should-advice · single
*You ___ see a doctor if the pain continues.*

- [x] should
- [ ] mustn't
- [ ] can't
- [ ] would

> Conseil : *should* + base verbale, sans *to* (« tu devrais »). Les modaux ne prennent jamais *to* après eux : *you should to see* est faux. *Ought to* a le même sens, avec *to*.
