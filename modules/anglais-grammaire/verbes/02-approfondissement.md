## remember-ing · single
*I clearly remember ___ the door, but now it's open!*

- [x] locking
- [ ] to lock
- [ ] lock
- [ ] to have lock

> *Remember* + *-ing* : se souvenir d'avoir fait (un souvenir). *Remember* + *to* : penser à faire (*Remember to lock the door*). Le sens change avec la construction.

## forget-to · single
*Don't forget ___ off the lights when you leave.*

- [x] to turn
- [ ] turning
- [ ] turn
- [ ] turned

> *Forget to do* : oublier de faire quelque chose à faire. *I'll never forget meeting her* : je n'oublierai jamais de l'avoir rencontrée (un souvenir).

## stop-ing · single
*He stopped ___ last year; he hasn't had a cigarette since.*

- [x] smoking
- [ ] to smoke
- [ ] smoke
- [ ] to smoking

> *Stop doing* : arrêter de faire. *Stop to do* : s'arrêter pour faire (*He stopped to smoke* : il s'est arrêté pour fumer). Contresens fréquent.

## make-base · single
*Our manager made us ___ the whole report again.*

- [x] write
- [ ] to write
- [ ] writing
- [ ] wrote

> *Make someone do something* (faire faire, obliger) : base verbale sans *to*. Au passif, le *to* réapparaît : *We were made to write it again.*

## let-base · single
*They let us ___ early on Friday.*

- [x] leave
- [ ] to leave
- [ ] leaving
- [ ] left

> *Let someone do something* (laisser, permettre) : base verbale. Synonyme avec *to* : *allow someone to do something*.

## would-like-to · single
*I'd like you ___ this form before the meeting.*

- [x] to fill in
- [ ] fill in
- [ ] that you fill in
- [ ] filling in

> *Want / would like someone to do something*. Le français « j'aimerais que vous remplissiez » pousse vers *I'd like that you fill in*, impossible en anglais.

## consider-ing · single
*The board is considering ___ the head office to Lyon.*

- [x] moving
- [ ] to move
- [ ] move
- [ ] to moving

> *Consider* (envisager) + *-ing*. De même : *imagine, risk, delay, postpone, recommend + -ing*.

## afford-to · single
*We can't afford ___ a new car this year.*

- [x] to buy
- [ ] buying
- [ ] buy
- [ ] bought

> *Afford to do* : avoir les moyens de faire. Avec un nom : *we can't afford a new car*.

## no-use-ing · single
*It's no use ___; the decision has been made.*

- [x] complaining
- [ ] to complain
- [ ] complain
- [ ] complained

> *It's no use / It's no good + -ing* : « ça ne sert à rien de ». Comparer : *there's no point (in) complaining*.

## deny-ing · single
*He denied ___ the money from the till.*

- [x] taking
- [ ] to take
- [ ] take
- [ ] to have take

> *Deny* + *-ing* (nier avoir fait), ou *deny having taken*. Mêmes verbes : *admit, regret* (au sens de « regretter d'avoir fait »).
