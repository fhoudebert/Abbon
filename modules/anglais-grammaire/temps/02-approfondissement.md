## by-the-time · single
*By the time we got to the cinema, the film ___.*

- [x] had already started
- [ ] has already started
- [ ] already started
- [ ] was already starting

> *By the time* + prétérit, puis past perfect pour ce qui s'était produit avant : le film avait déjà commencé.

## will-have-worked · single
*By next June, I ___ for this company for ten years.*

- [x] will have worked
- [ ] will work
- [ ] work
- [ ] am working

> Futur antérieur (*will have* + participe passé) : bilan à un moment futur. *By next June* (« d'ici juin prochain ») le signale.

## how-long · single
*How long ___ English?*

- [x] have you been learning
- [ ] are you learning
- [ ] do you learn
- [ ] did you learn

> « Depuis combien de temps apprends-tu l'anglais ? » : l'action dure encore, donc present perfect, ici progressif pour insister sur la durée. Le présent français est un piège constant.

## first-time · single
*This is the first time I ___ sushi.*

- [x] have eaten
- [ ] eat
- [ ] am eating
- [ ] ate

> *It's / This is the first (second…) time* est toujours suivi du present perfect. Le français dit « c'est la première fois que je mange des sushis », au présent.

## used-to · single
*When I was a child, I ___ to the beach every summer.*

- [x] used to go
- [ ] was used to go
- [ ] am used to going
- [ ] use to going

> *Used to* + base verbale : une habitude passée, révolue (l'imparfait français). À distinguer de *be used to + -ing* : « être habitué à » (*I'm used to getting up early*).

## arrangement · single
*I ___ the dentist tomorrow at 10; it's all arranged.*

- [x] am seeing
- [ ] see
- [ ] will be see
- [ ] would see

> Un rendez-vous déjà fixé pour le futur se dit au présent progressif : *I'm seeing the dentist tomorrow*. *Will* exprime plutôt une décision prise sur le moment ou une prévision.

## has-been-living · single
*She ___ in Paris since 2020.*

- [x] has been living
- [ ] lives
- [ ] is living
- [ ] lived

> Situation commencée en 2020 et toujours vraie : present perfect, progressif ou simple (*has lived* convient aussi). *She lives in Paris since 2020* est la faute typique.

## passive-signed · single
*The contract ___ by the director yesterday.*

- [x] was signed
- [ ] has been signed
- [ ] signed
- [ ] is signed

> Passif (*be* + participe passé) au prétérit, à cause de *yesterday*. *The contract signed* voudrait dire que le contrat a signé lui-même.

## third-conditional · single
*If I had known you were in town, I ___ you.*

- [x] would have called
- [ ] would call
- [ ] will have called
- [ ] had called

> Hypothèse sur le passé (troisième conditionnel) : *if* + past perfect, puis *would have* + participe passé. Mot à mot : « si j'avais su…, je t'aurais appelé ».

## i-wish · single
*I wish I ___ more time to read.*

- [x] had
- [ ] have
- [ ] would have
- [ ] will have

> *I wish* + prétérit exprime un regret sur le présent (« j'aimerais avoir plus de temps ») ; *I wish I had had* porte sur le passé. Le prétérit marque ici l'irréel, comme après *if*.
