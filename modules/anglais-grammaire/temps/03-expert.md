## mixed-conditional · single
*If he ___ the earlier train, he would be here by now.*

- [x] had caught
- [ ] caught
- [ ] would have caught
- [ ] has caught

> Conditionnel mixte : condition sur le passé (*had caught*), conséquence dans le présent (*would be here now*). Le français fonctionne de même : « s'il avait pris le train précédent, il serait déjà là ».

## high-time · single
*It's high time we ___. It's nearly midnight.*

- [x] left
- [ ] leave
- [ ] will leave
- [ ] are leaving

> *It's (high) time* + sujet + prétérit : « il est grand temps que nous partions ». Le prétérit exprime une action qui devrait déjà avoir lieu, pas un temps passé. Sans sujet : *it's time to leave*.

## would-rather · single
*I'd rather you ___ smoke in the car.*

- [x] didn't
- [ ] don't
- [ ] wouldn't
- [ ] not

> *Would rather* + autre sujet + prétérit : « je préférerais que tu ne fumes pas ». Avec le même sujet, base verbale : *I'd rather stay at home*.

## future-perfect · single
*By 2030, the company ___ its emissions by half.*

- [x] will have reduced
- [ ] will reduce
- [ ] reduces
- [ ] will be reducing

> Futur antérieur : action achevée avant une date future, introduite par *by*. *By half* signifie « de moitié ».

## future-continuous · single
*This time next week, I ___ on a beach in Crete.*

- [x] will be lying
- [ ] will lie
- [ ] lie
- [ ] will have lain

> Futur progressif : action en cours à un moment futur précis. *Lie* (être allongé) fait *lying* ; ne pas confondre avec *lay* (poser).

## must-have-left · single
*Her coat isn't here. She ___ left already.*

- [x] must have
- [ ] must
- [ ] should have
- [ ] can have

> Déduction sur le passé : *must have* + participe passé (« elle a dû partir »). Le contraire est *can't have left* (« elle ne peut pas être partie »). *Can have* n'existe pas dans ce sens.

## should-have · single
*You ___ told me you were ill! I would have helped.*

- [x] should have
- [ ] must have
- [ ] had to
- [ ] would have

> Reproche ou regret sur le passé : *should have* + participe passé (« tu aurais dû me le dire »). *Must have told me* serait une déduction (« tu as dû me le dire »).

## had-been-waiting · single
*When he finally turned up, I ___ for over an hour.*

- [x] had been waiting
- [ ] was waiting
- [ ] have been waiting
- [ ] waited

> Past perfect progressif : une action qui durait jusqu'à un moment passé (« j'attendais depuis plus d'une heure quand il est arrivé »). Le français met l'imparfait ; l'anglais exige le past perfect avec une durée.

## supposing · single
*Supposing you ___ the lottery, what would you do?*

- [x] won
- [ ] win
- [ ] will win
- [ ] would win

> *Supposing, suppose, imagine, what if* se construisent comme *if* : prétérit pour une hypothèse peu probable, puis *would*.

## must-be · single
*He's been working since 5 a.m. He ___ exhausted.*

- [x] must be
- [ ] can't be
- [ ] should have been
- [ ] can be

> Déduction sur le présent : *must be* (« il doit être épuisé »), et son contraire *can't be* (« il ne peut pas être épuisé »), qui contredit ici le contexte. *Can be* exprime une possibilité générale (*He can be very rude*), pas une déduction.
