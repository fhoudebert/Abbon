## not-only · single
*Not only ___ late, but he also forgot the documents.*

- [x] did he arrive
- [ ] he arrived
- [ ] he did arrive
- [ ] arrived he

> Après une expression négative ou restrictive placée en tête (*not only, never, rarely, seldom*), l'ordre est celui d'une question : auxiliaire + sujet + verbe (*did he arrive*). Registre soutenu, très testé à Cambridge.

## little-did · single
*Little ___ that he was being watched.*

- [x] did he know
- [ ] he knew
- [ ] knew he
- [ ] he did know

> *Little did he know…* : « il était loin de se douter que… ». Même inversion qu'avec *not only*.

## under-no-circumstances · single
*Under no circumstances ___ the emergency exit.*

- [x] should you block
- [ ] you should block
- [ ] you block
- [ ] block you

> *Under no circumstances / On no account* + inversion : « en aucun cas vous ne devez… ». Fréquent dans les règlements et les consignes de sécurité.

## had-i-known · single
*___ I known about the delay, I would have taken a later train.*

- [x] Had
- [ ] If
- [ ] Would
- [ ] Should

> Condition sur le passé sans *if* : *Had I known* = *If I had known*. *If I known* est impossible. De même : *Should you need help…* = *If you need help…*, *Were I you…* = *If I were you…*

## so-difficult · single
*So difficult ___ that only three candidates passed.*

- [x] was the exam
- [ ] the exam was
- [ ] did the exam
- [ ] the exam it was

> *So* + adjectif en tête de phrase entraîne l'inversion du sujet et du verbe : *So difficult was the exam that…* (version neutre : *The exam was so difficult that…*).

## what-i-need · single
*What I need right now ___ a long holiday.*

- [x] is
- [ ] are
- [ ] it is
- [ ] that is

> Phrase clivée (mise en relief) : *What I need is…* (« ce dont j'ai besoin, c'est… »). Le verbe s'accorde au singulier avec *what*, et pas de *it* : le calque de « c'est » donne la faute *What I need, it is…*

## as-if · single
*He talks as if he ___ the boss, but he only started last week.*

- [x] were
- [ ] is being
- [ ] will be
- [ ] would

> *As if / as though* + prétérit (ou *were*, à toutes les personnes en anglais soigné) pour une comparaison irréelle : il n'est pas le patron.

## non-defining · single
*The report, ___ I had read twice, still contained errors.*

- [x] which
- [ ] that
- [ ] what
- [ ] who

> Relative non restrictive (entre virgules, information ajoutée) : *which* pour une chose, *who* pour une personne, jamais *that*. Sans les virgules (relative restrictive), *that* conviendrait.

## number-of · single
*The number of applicants ___ risen sharply this year.*

- [x] has
- [ ] have
- [ ] are
- [ ] were

> *The number of* + pluriel : le sujet est *number*, singulier (*the number has risen*). Mais *a number of* (« un certain nombre de ») se construit au pluriel : *A number of applicants have withdrawn.*

## neither-nor · single
*Neither the manager nor the employees ___ informed of the change.*

- [x] were
- [ ] was
- [ ] has been
- [ ] is

> Avec *neither… nor* et *either… or*, le verbe s'accorde avec le sujet le plus proche : *the employees*, pluriel, donc *were*. Avec *Neither the employees nor the manager*, on écrirait *was*.
