## too-heavy · single
*This box is ___ heavy for me to lift.*

- [x] too
- [ ] enough
- [ ] very
- [ ] so

> *Too* + adjectif : trop (au point que c'est impossible). *Very heavy* (très lourd) ne dit pas qu'on ne peut pas la soulever. Construction : *too* + adjectif + *for someone* + *to* + verbe.

## old-enough · single
*She's old ___ to drive.*

- [x] enough
- [ ] too
- [ ] enough age
- [ ] very

> *Enough* se place **après** l'adjectif (*old enough, good enough*), mais **avant** le nom (*enough money*). Le français « assez âgée » pousse à écrire *enough old*.

## although · single
*___ it was raining, we went out.*

- [x] Although
- [ ] Despite
- [ ] However
- [ ] Because

> *Although* (bien que) + proposition complète (sujet + verbe). *Despite* est suivi d'un nom ou d'un gérondif (*despite the rain*). *However* (cependant) relie deux phrases : *It was raining. However, we went out.*

## more-interesting · single
*This book is ___ than the one I read last week.*

- [x] more interesting
- [ ] interestinger
- [ ] most interesting
- [ ] interesting

> Adjectifs longs (deux syllabes ou plus, sauf ceux en *-y*) : *more* + adjectif + *than*. Courts : *-er* (*bigger, cheaper*). *Most* sert au superlatif (*the most interesting*).

## more-fluently · single
*She speaks English ___ than I do.*

- [x] more fluently
- [ ] most fluently
- [ ] fluentlier
- [ ] fluently

> *Fluently* est un adverbe (il complète *speaks*) : son comparatif est *more fluently*. Un adjectif serait faux : *she speaks English more fluent*.

## question-tag · single
*You're coming tomorrow, ___?*

- [x] aren't you
- [ ] are you
- [ ] do you
- [ ] won't you

> Le *question tag* (« n'est-ce pas ? ») reprend l'auxiliaire de la phrase, à la forme inverse : phrase affirmative avec *are*, tag négatif *aren't you?* Il n'y a pas de formule invariable comme « n'est-ce pas ».

## never-drink · single
*I ___ coffee in the evening.*

- [x] never drink
- [ ] drink never
- [ ] drinks never
- [ ] never drinks

> Les adverbes de fréquence (*never, always, often, usually*) se placent avant le verbe principal, mais après *be* : *I never drink coffee*, *I'm never late*. Le français « je ne bois jamais » donne la faute *I drink never*.

## an-engineer · single
*She's ___ engineer.*

- [x] an
- [ ] a
- [ ] the
- [ ] (pas d'article)

> Deux pièges. Pour un métier, l'anglais met un article (« elle est ingénieure », sans article en français). Et c'est *an* devant un son voyelle : *an engineer, an hour*, mais *a university* (son « you »).

## neither · single
*Neither of them ___ ready.*

- [x] is
- [ ] are
- [ ] were
- [ ] be

> *Neither of* (aucun des deux) se construit, en anglais soigné, avec un verbe au singulier : *neither of them is*. Le pluriel (*are*) s'entend à l'oral, mais l'examen attend le singulier. De même avec *either of* et *each of*.

## indirect-question · single
*Could you tell me where ___?*

- [x] the station is
- [ ] is the station
- [ ] the station it is
- [ ] does the station

> Dans une question indirecte (*Could you tell me…, I wonder…, Do you know…*), l'ordre est celui d'une affirmation : sujet + verbe. *Where is the station?* devient *…where the station is*.
