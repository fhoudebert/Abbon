## Ordre des mots

- Adverbes de fréquence avant le verbe principal, après *be* : *I never drink coffee. I'm always late.*
- *enough* après l'adjectif (*old enough*), avant le nom (*enough money*) ; *too* + adjectif (*too heavy to lift*).
- Question indirecte : ordre affirmatif, sans *do* : *Could you tell me where the station is? She asked me where I lived.*

## Articles

- Métier : *She's an engineer* (article obligatoire).
- *an* devant un son voyelle (*an hour, an engineer*), *a* devant un son consonne (*a university*).

## Comparaison

- *taller than* ; *more interesting than* ; adverbes : *more fluently than*.
- Égalité : *as tall as* ; *the more…, the better*.
- *such a good film* / *so good*.

## Liaisons

- *although* + proposition ; *despite / in spite of* + nom ou *-ing* ; *however* entre deux phrases.
- *whether* : si (interrogation indirecte).
- Relatives : *whose* + nom (dont) ; *that* après un superlatif ; entre virgules, *which* ou *who*, jamais *that*.

## Question tags

Auxiliaire de la phrase, à la forme inverse : *You're coming, aren't you? She didn't call, did she?* Après *Let's…* : *shall we?*

## Accords

- *Neither of them is* (soigné) ; *everybody is* ; *the number of… has* mais *a number of… have* ; *neither… nor* : accord avec le sujet le plus proche.

## Inversions (registre soutenu)

Après une expression négative ou restrictive en tête : auxiliaire + sujet.

- *Not only did he arrive late, but…* ; *Little did he know…* ; *Under no circumstances should you…* ; *So difficult was the exam that…*
- Sans *if* : *Had I known…*, *Should you need…*, *Were I you…*
- Mise en relief : *What I need is a holiday.* Irréel : *as if he were the boss*.
